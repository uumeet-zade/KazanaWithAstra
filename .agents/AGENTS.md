# Workspace Rules for KazanaWithAstra

## Design Guidelines
- **UI Corners**: Use sharp corners or very minimal border-radius. Absolutely NO very soft, rounded corners on buttons, cards, or other UI elements.
- **Color Palette**: 
  - Primary: `#220735` (Deep Purple)
  - Secondary: `#8c263e` (Burgundy)
  - Accent: `#ff2459` (Vibrant Pink/Red)

## Content and Phrasing Guidelines
- **Em Dashes**: Absolutely NO em dashes (-) can be used in text or content. Use alternative punctuation if necessary, but never an em dash.
- **Phrasing Restrictions**: Do NOT use the phrasing structure "is not [X], but [Y]" or any close variation of it in any text or copy.

## Context
- **Lore**: Caprica (Country), Kazana (Region), 2062 Gubernatorial Elections.
- **Candidate**: Astra Day (Incumbent Governor of Kazana since 2060).
- **Party**: Kazana's Left (regional affiliation of the Rejuvenation Party).
- **Ideology**: Left-Wing to Far-Left, Left-Wing Populism, Anti-Capitalism, Progressivism, Environmentalism, Decentralisation.

## Assets and Content Generation
- **Images and Logos**: Do NOT generate images, logos, or visual assets using Gen AI. The user will provide the exact images to be used. If the Agent absolutely MUST generate an image placeholder structurally, stick exclusively to SVG format.
- **Platform Text**: The Agent IS allowed to generate text (platform, hero, about, etc.) based on the provided lore and ideological constraints.

## Languages
- **Supported Languages**: The simulator/website must support language options:
  - **Alanian** (English)
  - **Gallic** (French)
